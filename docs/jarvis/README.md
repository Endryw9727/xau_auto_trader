# jarvis — mirror del vault Obsidian

Questa cartella contiene note in stile Obsidian pensate per il **secondo cervello**
(vault "jarvis"). Il vault vero vive in un repository git separato; queste note
sono scritte qui perché la sessione di sviluppo è vincolata al repo
`xau_auto_trader`. Copiale/sincronizzale nel vault, oppure — se il repo del vault
viene aggiunto allo scope della sessione — verranno scritte direttamente lì.

Le note usano frontmatter YAML, tag e `[[wikilink]]` così da integrarsi
nativamente in Obsidian.
